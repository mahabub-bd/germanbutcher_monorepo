# Feature Update List — Additions
**October 28, 2026** (append to the October 28 list under a new section)

## CRM & Marketing

1. **Customer Area & Mobile Columns (New)**
The CRM customer list and the Top VIP Customers table on the CRM dashboard now show each customer's delivery area (e.g. Badda, Gulshan, Mirpur DOHS — taken from their default address) and a clickable mobile number.

2. **Customer 360 Page — Redesigned**
The customer detail page now uses a cleaner tab layout (Orders, Cart & Wishlist, Shipping, Reviews, Messages, Activities) with icons and count badges, and the profile stats (Orders, Total Spent, Avg Order, Last Order) use the same stat card design as the CRM dashboard for a consistent look.

3. **Shipping Addresses Tab (New)**
A new Shipping tab on the customer page lists every saved address — area as the heading, full street address, city/division, and Shipping/Billing/Default badges.

4. **Top VIP Customers Enhancements**
Top three customers get ranked (gold/silver/bronze) avatars, each row shows the customer's segment badge, area, mobile number, and a "View All" link to the full customer list.

5. **Customer List Export to CSV (New)**
The CRM customer list has a "Download CSV" button that exports all customers matching the current segment/search filter — with name, email, mobile, area, order counts, spend and segment — ready for Excel.

6. **SMS & Email Campaigns (New Feature)**
New "CRM Campaigns" admin page to send bulk SMS or email blasts to a customer segment (VIP, Loyal, At Risk, New, Inactive, or all customers). Includes a live "will reach N customers" preview before sending, message personalization with the customer's first name, background delivery, and a per-customer delivery log showing exactly who was sent/failed/skipped and why. Every campaign is created as a draft and only sends after confirmation.

7. **Sidebar Highlight Fix**
On CRM pages, only the currently open menu is highlighted in the admin sidebar (previously both CRM Dashboard and CRM Customer lit up together).

8. **Orders List Page Size**
The admin orders list now shows 12 orders per page by default.
