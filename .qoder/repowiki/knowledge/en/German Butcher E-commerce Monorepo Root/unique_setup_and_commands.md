Local dev: `pnpm install` then `pnpm dev` (or `pnpm dev:frontend` / `pnpm dev:backend`). Production containers: `pnpm docker:up` / `pnpm docker:down` / `pnpm docker:logs`. Requires `apps/frontend/.env` and `apps/backend/.env` before compose starts; environment variables are also passed as Docker build ARGs (`NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_BASE_URL`, `NEXT_PUBLIC_SOCKET_URL`) into the frontend image.
