This is the repository root of a two-app monorepo. The workspace is declared in `pnpm-workspace.yaml` with `packages: ['apps/*']`, so the actual application code lives under `apps/frontend` (Next.js 16 App Router) and `apps/backend` (NestJS 11), which are out of this leaf's scope. The root `package.json` exposes unified scripts (`dev`, `build`, `start`, plus per-app variants) that delegate to each app via `pnpm --filter`. Containerization uses two multi-stage Dockerfiles — `Dockerfile.frontend` builds a Next.js standalone output on Node 24 Alpine, and `Dockerfile.backend` compiles TypeScript then runs the NestJS dist as a non-root `nestjs` user on Node 24 Alpine. `docker-compose.yml` wires both services onto a shared `germanbutcher-network`, reads env files from `apps/{frontend,backend}/.env`, and adds healthchecks against `/v1` (backend) and port 3002 (frontend). Documentation and production SQL migrations live in `docs/` and `sql/` respectively; `.claude/settings.local.json` holds local Claude Code settings. Dependency resolution pins Next 16.4.3 binaries via `minimumReleaseAgeExclude` and allows native build packages (`bcrypt`, `sharp`, `unrs-resolver`) through `allowBuilds`.
